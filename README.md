# lowcode-project

The application we build together across the **Certificate in Low-Code, No-Code &
AI-Assisted Application Development** at CCT College Dublin.

QQI Level 7 · 10 ECTS · Wednesdays 18:30–21:30 · Autumn 2026 / January 2027

## How this repository grows

One application, built a layer at a time. Each week adds to the last, so the
repository at the end of the course *is* the portfolio submission.

| Week | What lands here |
|---|---|
| 3 | The generated task app: the first thing that runs |
| 5 | A schema, so the data has a shape |
| 6 | A front end |
| 7 | Tests |
| 8 | The security fixes, with the findings that prompted them |
| 9 | A container |
| 10 | A deployment |
| 11 | Governance: licences, dependencies, who is accountable for what |

## If you miss a week

Weeks 3 and 9 are the two that leave you genuinely stuck rather than merely
behind, because everything after them assumes they exist. Each lesson plan names
a recovery task — do that before the next session rather than after it.

## Commit as you go

Commit at the end of every session, even when it does not work. A repository
with eleven honest commits shows the build; one with a single drop at the end
shows nothing, and is worth less in the assessment for exactly that reason.
